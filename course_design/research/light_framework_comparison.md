

I'm starting to lean toward Mastra. It has everything we would want for this course, and gives simple guides for useful things like Slack integration.

Pros
- Low floor, high ceiling
- Very readable
- Teaching resources
    - [Principles of Building AI Agents](https://mastra.ai/books/principles-of-building-ai-agents)
    - [Patterns for Building AI Agents](https://mastra.ai/books/patterns-of-building-ai-agents)
- Trivially easy integration with any observability platform
- Takes the best parts of a lot of frameworks
- Super easy out of the box pieces without over-prescribing
- Simple guides for useful things like Slack integration
- Small. Easy to navigate documentation.

Cons
- Students are trained in Python
- Lacks easy notebook start
    - [Environment Solution](https://chatgpt.com/share/6a5bcace-a150-83e8-a4d1-bfbbdb9bba5d)
- Course is structured as a Quarto website (Python-native)
- Python is far more friendly to Data Scientists

LangChain ecosystem
Pros
- Python-first
- Full ecosystem
- Granular level control up to highly opinionated agents

Cons
- Bloated
- AI writes bad code
- DeepAgents doesn't teach, LangGraph is too hard
    - If you aren't in the right zone (LangChain), it's high floor, low ceiling
- Difficult to integrate with frontend (a necessary step)

## Don't Stop There

Here is a broader [comparison](https://share.gemini.google/1DrrcfpOcmiu) of more frameworks

It may benefit students to show multiple frameworks. Some have different entry points.

Overall, if you use a framework, you have to subscribe to its assumptions and beliefs and assess if it fits your use case.

It would be nice to run evals against multiple frameworks. I just want to make sure students have adequate support if they fall behind.

Or, they could learn a new framework mid-class. That would definitely evaluate the self-learning outcome.
