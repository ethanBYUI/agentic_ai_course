Use Cases → Course Competencies (LangChain)

Maps every entry in the use-case coverage inventory to the outcomes and competencies in the course outcomes doc, and — where a concrete build exists — to a worked LangChain example or a real case study that demonstrates it.

The companion doc inventories what LangChain material exists per use case. This one answers a different question: which competency does building that thing actually exercise? A use case is only worth picking for an activity if it earns its place on both axes — it should teach something on the outcomes rubric, not just fill a breadth checkbox.

Competency codes

Reference the numbering in course_outcomes.md directly (e.g. 1.5.2 = "Connect a sandbox for arbitrary code execution"). Only codes a use case exercises distinctively well are listed — nearly every agent build touches 1.1–1.2 trivially, so those are omitted unless there's a specific reason to highlight them.

Examples vs. case studies

Worked example links to an in-docs LangChain tutorial or capability guide (🟢/🟡 depth in the companion doc). Case studies links to entries on the LangGraph case-studies roster (🔗 depth) — external proof, not an in-docs build.

What isn't repeated

Breadth itself is the evidence for 5.5, which no single use case can satisfy, so it isn't repeated on every row. Rows call out 6.x (personal ethic) only where the use case raises a sharper ethical question than the baseline.

Notable pairings for planning activities

Each of these answers a planning question you'd actually ask while building the activity sequence.

If you need one activity that hits most of Outcome 1 at once
Customer Support

handoffs-customer-support is the strongest candidate — the only 🟢 tutorial that exercises model selection, prompt design, memory, tool calls, HITL, and multi-agent handoff in a single build.

If you need a rubric-grading / LLM-as-judge exemplar for Outcome 2
Education

RAG with Deep Agents ships an actual rubric-graded retrieval loop in-docs — closer to competency 2.2.2 than anything else in the catalog.

If you need a case where AI-fit judgment (Outcome 3) is the whole point, not a build
Manufacturing · Media & Gaming · Agriculture · Emergency Response

The "mostly ⚪" use cases. Assign one of these when the goal is teaching 3.2 viability assessment rather than another harness build.

If you need the sharpest ethics cases for Outcome 6
Healthcare · Legal · Emergency Response · Government

Healthcare and Legal for privacy and liability; Emergency Response for life-safety with no framework guardrail to lean on; Government for public-trust alignment framing.

If you need a use case with zero in-docs scaffolding, to test composing primitives from scratch (3.6)
Sales · Non-profit

The two thinnest verticals — both 🟠 / case-study-only, with no dedicated tutorial to imitate.
