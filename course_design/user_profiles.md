# User Profiles On Exit

## User 1: Brownfielder

Student walks into a new role at a company and is given an agent to diagnose and fix up.

This course should give them confidence to:

- Walk in, ask, and answer:
    - Does it work?
    - Is it aligned?
    - Is it ethical?
    - What implicit rules have we not defined?
    - What does the agent need to know that it doesn't?
- Redefine or revise agent
- Communicate findings, changes, and improvements to management and coworkers


## User 2: Greenfielder

Student is hired onto or is co-founder of a new tech startup solving a novel problem using AI agents.

This course should give them confidence to:

- Ask meaningful questions about the user experience
- Plan agent harness around unit level intent
- Build a new agent that works reliably

Outside the scope of this course is:

- Turning an agent into a product with meaningful UI beyond a basic chat interface
- Hosting and scaling the agent


## User 3: Personal Use

Student creates an agent for personal use.

This course should give them confidence to:

- Create within bounds of personal ethics and safety restrictions
- Generalize skills to easy-iteration, high-abstraction tools, and to new tools/languages



# User Profiles on Entry

## User 1: Fresh

Has taken Intro to programming and is still exploring their options. They are exploring agent development as a career path.


## User 2: Data Scientist

Has taken DS 250 and is not the greatest programmer, but is skilled in data analysis and abstraction.


## User 3: Software Engineer

Has taken upper level software courses and is skilled with Claude Code. Has never made an agent before.


## User 4: Agent Maker

Has made several agents, but does not have the skill to assess, diagnose objectively, and implement reliability standards like safety guardrails.
